# **App Name**: ImageDescriber

## Core Features:

- Image URL Input: Accept a URL from the user as input for the image to be described.
- API Key Input: Accept the user's Gemini API key as input.
- Image Description Generation: Generate a description of the image based on the user's API key and image URL using the Gemini Vision API.
- Description Display: Display the generated description to the user in a clear and readable format.

## Style Guidelines:

- Primary color: Muted indigo (#5C6BC0) to inspire confidence and intelligence.
- Background color: Very light grey (#F5F5F5), almost white.
- Accent color: Analogous blue (#64B5F6), for interactive elements.
- Body and headline font: 'Inter' for a clean, modern look suitable for both headlines and body text. 
- Use simple, outlined icons for controls.
- Keep the layout clean and minimal, with a focus on readability and ease of use.
- Use subtle animations for loading and transitions to enhance user experience.
